# Modeling Longitudinal Data

### Robert Weiss

Data sets and related resources accompanying:

**[Weiss, R. E. (2005). *Modeling Longitudinal Data*. Springer.](https://link.springer.com/book/10.1007/0-387-28314-5)**

This repository preserves the data sets and related resources that accompanied *Modeling Longitudinal Data* and were formerly distributed through Robert E. Weiss's UCLA website.

[Archived Book Data Sets page](https://web.archive.org/web/20231003041240/https://robweiss.faculty.biostat.ucla.edu/book-data-sets)
